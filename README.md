# VNETSEC Portfolio

## Run locally
1. Extract this ZIP.
2. Open the `network-cyber-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Personalise before publishing
- Replace `YOUR-USERNAME` in `index.html` with your GitHub username.
- Replace `YOUR-EMAIL@example.com` with your email address.
- Update the project repository links when your repositories are ready.
- Update project statuses as you complete and test each project.

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive dark networking/cybersecurity theme
- `javascript.js` — mobile menu, year and reveal animations
- `assets/profile.png` — your supplied portrait
- `assets/network-background.jpg` — your supplied network background
